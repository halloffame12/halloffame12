<h2 align="center">📐 Engineering Principles</h2>

<p align="center">
  <strong>Clean & Scalable Architecture:</strong> Code should be written to be read by engineers and executed cleanly by systems. I prioritize decoupling and single-responsibility structures.<br /><br />
  <strong>Data-Driven Optimization:</strong> I avoid guessing performance targets. I rely on profiling, timing logs, and clear system constraints to identify and resolve true bottlenecks.<br /><br />
  <strong>Developer Experience (DX):</strong> High-quality developer tooling increases product iteration safety and team throughput. Engineering tools should remain simple, focused, and deterministic.<br /><br />
  <strong>User-Centric Execution:</strong> Backend reliability, rigorous type checking, and system optimization serve a singular purpose: delivering reliable, low-latency experiences to users.
</p>
